What this is

A classifier separates electron-neutrino events (signal) from muon-neutrino events (background) using 50 detector measurements. In a real deployment some of those measurements can disappear. This app lets you switch sensors off and compare a normally trained XGBoost model with one trained on a mix of clean and sensor-dropout data.

What runs where

The models run in a Flask API on a machine you control. This Angular page only collects the 50 values and shows the answers. On a public static host such as GitHub Pages there is no Python, so the page falls back to the saved study results unless an API address has been configured at deploy time.

Limits

This is a coursework prototype. The study covers zeroed sensors and Gaussian noise on tabular accuracy; it is not a validated physics analysis, and a result on one dataset does not show the same gain elsewhere.
